SheraTutor Redesign Plan

A full UI/UX redesign and dependency-modernization plan for the SheraTutor web app (Next.js 16 App Router) — Bangladesh's AI board examiner for SSC & HSC students. Bangla-first, mobile-first, built on a new "খাতা" (exam script) visual identity.

3 · Research digest (what "current" looks like)

  • Next.js 16.3: Cache Components ("use cache") make caching explicit and opt-in; Instant Navigations (client-side caching + Suspense + partial prefetching) makes App Router transitions feel native-app fast — directly relevant for the dashboard-tab feel on mobile. Turbopack disk caching is on by default. next lint is gone; run ESLint directly. Best practice: put "use cache" next to the data access, wrap dynamic reads in Suspense.
  • shadcn/ui (Feb 2026): unified radix-ui package, data-slot attributes on every primitive, tw-animate-css, Tailwind v4 @theme inline tokens — this codebase already follows all of it. The redesign is a re-theming + composition job, not a component-library migration.
  • Genkit 1.41: current latest; new middleware plugin (retries, model fallbacks, tool approval); flows + @genkit-ai/next handlers remain the recommended Next.js integration. Streaming flow responses to the client is supported and should replace the tutor's current blocking JSON round-trip.
  • EdTech UX 2026: mobile-first with large CTAs; progressive disclosure (3–5 items first); AI feedback made visible and explainable; gamified momentum without dark patterns; onboarding that shows value in the first seconds; cross-device continuity.
  • Bangla web typography: Google Fonts' Bengali coverage is now strong — Noto Sans Bengali (most reliable rendering, full weight axis), Anek Bangla (variable width+weight, contemporary UI voice, with a matching Anek Latin superfamily), Tiro Bangla (a text serif designed for Bangla literature), plus the current Hind Siliguri / Baloo Da 2. Subset with next/font, always declare Bengali-capable fallbacks, and test conjuncts (যুক্তাক্ষর) at small sizes.

4 · The new identity — «খাতা» (the exam script)

The current brand (coral/mint/navy, bouncy Baloo) reads as a generic Western ed-app. The product's actual world is more specific and more powerful: the ruled exam khata, the examiner's red pen, and the blackboard. Every Bangladeshi student knows the red margin line down a script page and what red ink in it means. That becomes the brand.

Light theme = paper khata; dark theme = blackboard with chalk-tinted text. The green/red pairing quietly echoes the flag without literalism. Semantic scale for mastery: green (mastered) / ochre (review) / red (critical gap) — replacing today's mint/sunshine/coral, and never encoded by color alone (always paired with a mark glyph: ✓, △, ✗).

Typography — Bangla-first

Display & UI — Anek Bangla + Anek Latin (variable wdth/wght, one superfamily, one voice in both scripts)
তোমার খাতা, বোর্ড পরীক্ষকের চোখে · Graded like the board
Body — Noto Sans Bengali (best conjunct rendering at small sizes, full weight range) + Noto Sans for Latin
প্রতিটি ধাপে কোথায় নম্বর কাটা গেল, তা সঙ্গে সঙ্গে দেখো। যুক্তাক্ষর পরীক্ষা: ক্ষ, জ্ঞ, ত্র, শ্রু, ন্ত্র।
Editorial serif (landing hero only) — Tiro Bangla, the "textbook" voice
প্রশ্ন সহজ, উত্তর তোমার।

Marks, scores and stats keep a tabular treatment (font-variant-numeric: tabular-nums) with optional Bengali numerals (০–৯) via a user toggle. All loaded through next/font/google with bengali + latin subsets and display: swap.

Signature element

The red margin rule: a single 2–3 px examiner-red line marking key surfaces (section headers, the score column of a graded answer, the active nav item) — exactly like the margin of a khata page. It is the one bold gesture; everything else stays quiet paper-and-ink.

5 · Page-by-page redesign

App shell (mobile-first)

  • Mobile (<768 px): replace the hamburger sheet with a 5-item bottom tab bar — বাড়ি (Home), খাতা জমা দাও (Upload, center, raised, red), ফলাফল (Results), টিউটর (Tutor), আরও (More → study plan, practice, profile). Thumb-reach, 48 px+ targets, env(safe-area-inset-bottom).
  • Desktop: keep the sidebar, add Practice Generator (currently orphaned) to the nav, active item carries the red margin rule.
  • Enable Next 16.3 Instant Navigations + per-tab loading.tsx skeletons so tab switches feel app-native.

Landing page

  • Bangla-first copy with English toggle; hero set in Tiro Bangla over paper texture.
  • Hero shows the product, not claims: a marked khata page — handwritten answer, red rubric annotations, score — as the first visual (static image or lightweight animated reveal).
  • Keep waitlist form above the fold on mobile; add a "how it works" strip (ছবি তোলো → AI পরীক্ষক দেখে → ধাপে ধাপে ফল) and a trust section for the free-forever promise.

Auth + onboarding

  • Split onboarding into a 3-step wizard (exam → board/group → consent) with progress marks; Bangla labels with English board names preserved.
  • Guardian consent becomes its own dignified step (not a grey box): plain-Bangla explanation of PDPA 2026, phone field with inputmode="tel" and ০১ prefix hint.

Dashboard

  • Progressive disclosure: today's 3 quick wins first, then momentum, then heatmap.
  • Heatmap cells get mark glyphs + Bangla chapter titles (title_bn is already in the query but unused — today it renders English only).
  • Momentum becomes a drawn-stroke progress arc with the score in tabular figures; empty states written as invitations ("প্রথম খাতা জমা দাও — ৫ মিনিটেই ফল").

Upload — camera-first

  • Primary action opens the camera (capture="environment"); gallery picker secondary.
  • Page-by-page capture flow with thumbnail strip, reorder, retake; client-side downscale/compress before upload (Bangladesh mobile data is expensive); clear per-page upload progress and resumability.

Submission detail — the marked script (hero feature)

  • Design it as a digital khata: each question a "script section" with the score in a red-ruled margin column, rubric steps as examiner ticks (✓ full, △ partial with reason, ✗ missed step highlighted).
  • "সহজ করে বুঝাও" (explain simply) stays per-step; transcript-mismatch flagging surfaced as "আমার লেখা ভুল পড়া হয়েছে" with the page image side-by-side on desktop, stacked on mobile.
  • Grading-in-progress state becomes a staged timeline (uploaded → transcribed → grading → done) driven by the existing queue statuses.

Tutor chat

  • Mobile: full-screen chat; sessions move into a slide-in drawer; subject/chapter pickers collapse into a single context chip.
  • Stream responses via Genkit streaming flows instead of blocking JSON; render markdown + KaTeX (deps already installed but the panel renders plain text today).
  • Desktop keeps the two-pane layout with the khata paper background.

Study plan

  • "আজকের পড়া" (today) card first and large, rest of the 14-day cycle as a compact horizontal scroller on mobile / grid on desktop; rest days styled as breathing room, not 50 %-opacity cards.
  • Each chapter links to tutor chat pre-scoped to that chapter (route already supports it).

Practice generator + profile

  • Promote generator into nav; result renders as a printable board-style question paper (Tiro Bangla, proper ক/খ/গ numbering) with a print stylesheet.
  • Profile gains language preference (বাংলা/English), Bengali-numeral toggle, and theme control (light "paper" / dark "blackboard" / system via existing next-themes).

6 · Bangla-first localization strategy

  • Today only the tutor page is Bangla while <html lang="bn"> — the reverse of correct. Flip the default: UI copy in Bangla, English as the toggle. Centralize strings in a lightweight dictionary (src/lib/i18n/bn.ts / en.ts) — no heavy i18n framework needed at this scale.
  • Mark Latin-only fragments with lang="en" spans so the existing :lang() font switching keeps working.
  • Database already stores title_bn/name_bn everywhere — render them.

7 · Responsive, accessibility & performance bar

  • Target device: low-end Android, 360×800, spotty 4G. Budget: <200 KB JS on landing, LCP <2.5 s on Slow 4G, font subsets only (Bengali subset of Noto Sans Bengali ≈ heavier than Latin fonts — preload the body face, lazy-load Tiro Bangla).
  • All touch targets ≥44 px; forms use correct inputmode; bottom-bar pages get scroll-padding.
  • WCAG 2.1 AA: mark glyphs alongside every color encoding, visible focus rings (green on paper, chalk on blackboard), prefers-reduced-motion respected on all transitions.
  • Use "use cache" on subject/chapter lookups and landing content; keep grading data dynamic with Suspense boundaries.

8 · Implementation roadmap

Phase 0 — Foundations (½ day)

Safe package bumps (table above) · adopt genkit-plugin-middleware retries/fallbacks · verify build + eval script still green.

Phase 1 — Design system (1–2 days)

New tokens in globals.css (khata palette, both themes) · font swap in layout.tsx (Anek Bangla/Latin, Noto Sans Bengali, Tiro Bangla) · re-theme the 17 shadcn primitives · build the margin-rule + mark-glyph primitives · string dictionary scaffold.

Phase 2 — Shell + high-traffic pages (2–3 days)

Bottom tab bar + sidebar · dashboard · upload (camera-first) · submission detail as marked script.

Phase 3 — Conversion + remaining pages (2 days)

Landing · auth + onboarding wizard · tutor chat (streaming + markdown/KaTeX) · study plan · practice generator promotion · profile settings.

Phase 4 — Polish & proof (1 day)

Instant Navigations + use cache pass · Lighthouse mobile run on throttled profile · a11y sweep · dark-mode sweep · real-device Bangla conjunct check.
