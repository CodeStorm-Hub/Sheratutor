⚠ The Unescaped Angle Bracket Problem

27 files in docs/crawled_docs/ and docs/PHYSICS_AUDIT_FINDINGS.md contain code snippets like az cognitiveservices account <resource-name>. React/MDX compilers interpret <resource-name> as an unclosed JSX tag and throw fatal syntax errors during static compilation. MkDocs parses standard CommonMark and does not treat them as JSX.
