# Implementation Plan: SheraTutor Docs Redesign, Contrast Fix, Explorers Hub & Full Corpus Audit

Redesign the SheraTutor documentation website, fix critical dark-on-dark link visibility bugs, build a dedicated Interactive Visual Explorers Showcase Hub, resolve broken links across all folders in `docs/`, and apply modern web design guidelines.

## User Review Required

> [!IMPORTANT]
> **Contrast Fix (Dark-on-Dark Text)**:
> In `slate` dark mode, links and active sidebar items were inheriting `#14182B` (Ink Navy), matching the background and rendering them invisible until hovered. We are applying WCAG AAA compliant tokens:
> - Dark mode links: `#38BDF8` (Sky Blue, 8.2:1 contrast against `#0F1322` background) with `#23D9A5` (Mint) on hover.
> - Active sidebar/tab items: `#23D9A5` with subtle pill tint `rgba(35, 217, 165, 0.12)`.
> - Card titles: Explicit `#F8FAFC` high-contrast styling with coral/mint accent badges.

> [!IMPORTANT]
> **Interactive Visual Explorers Hub**:
> Instead of immediately redirecting the "Interactive Visual Explorers" tab to a single HTML file, we are introducing a showcase hub at `docs/antigravity-docs/explorers.md`. It features dedicated preview cards, tech tags, and launch buttons for all 6 interactive applications and presentations:
> 1. `sheratutor_interactive_explorer.html` (Full Architecture Explorer)
> 2. `genkit_interactive_explorer.html` (Google Genkit Next.js Explorer)
> 3. `sheratutor_genkit_integration_explorer.html` (7 Grading Flows & Integration)
> 4. `foundry_interactive_explorer.html` (Azure Foundry Architecture)
> 5. `sheratutor_docs_audit_dashboard.html` (Corpus Audit & Quality Metrics)
> 6. `pitch/BoardMate_AI_Pitch_Deck.html` (Interactive BoardMate Pitch Deck)
