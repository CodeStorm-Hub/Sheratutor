Layer 1: Vision Transcription

Input Artifacts & Constraints

Input: Uploaded page JPEG/PNG signed URL from exam-submissions bucket.

Anti-Correction Prompting: The Vision LLM is explicitly forbidden from fixing student arithmetic errors, misspellings, or missing units. If a student wrote 5 + 3 = 9, the OCR transcript MUST read 5 + 3 = 9.

Uncertain Spans: Bounding text fragments where image blur or handwriting legibility is low are flagged in ocr_uncertain_spans.

Autonomous Socratic Tutor Agent (Genkit defineAgent)

Multi-turn pedagogical agent powered by SupabaseSessionStore, tool calling, and Human-In-The-Loop interrupts.

tutorAgent
AGENT

Socratic Pedagogy Engine

Defined via ai.defineAgent in web/src/ai/agents/tutor-agent.ts. Guided by strict pedagogical rules:

  • One Leading Question at a Time: Never dumps the final answer. Patiently guides the student to isolate variables and formulas.
  • No Repetitive Greetings: Forbids opening with "হ্যালো!" or "আসসালামু আলাইকুম!". Dives straight into guidance.
  • Strict LaTeX Demarcation: All math expressions wrapped in $formula$; Bengali text strictly excluded from LaTeX tags.
model: MODELS.reasoning (gpt-oss-20b)

PGMQ

Asynchronous Queue & pg_cron Pipeline

Autonomous Worker
1. Enqueue Job (enqueue_grading_job)

When a student submits an exam, the API route calls this SECURITY DEFINER function to push a payload into pgmq's grading_queue.

2. Scheduled Poller (pg_cron + pg_net)

Configured in migration 034: fires every 60s (* * * * *) using net.http_post to trigger /api/internal/process-grading-queue with the bearer token retrieved securely from vault.decrypted_secrets.

3. Worker Execution & Visibility Timeout

Worker locks up to 5 jobs with a 120s visibility timeout. Runs gradeSubmissionFlow using service-role client. Retries up to 3 times before dead-lettering to FAILED.

Fail-Closed Security: If the secret is missing from Vault, the header is omitted and the worker endpoint returns 401 Unauthorized instead of accepting hardcoded credentials.
