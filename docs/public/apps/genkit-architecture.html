Next.js App Router Full-Stack Architecture

How Genkit achieves zero-CORS full-stack AI, streaming structured outputs, and type safety with zero client-bundle bloat.

STEP 1 • CLIENT

streamFlow() Call

Browser sends HTTP POST with Accept: text/event-stream. Flow types are imported as import type so no Genkit runtime is bundled in client JS.

POST /api/generate
{ "data": { "prompt": "..." } }
STEP 2 • ROUTE HANDLER

appRoute() Adapter

appRoute(flow) intercepts NextRequest, runs contextProvider for auth/headers, parses body with Zod, and initializes a Web TransformStream.

NextResponse(readable, {
  headers: 'text/event-stream'
})
STEP 3 • SERVER RUNTIME

Action Execution Loop

Genkit executes flow inside OpenTelemetry root span. Model generates tokens & executes tools. Chunks are dispatched via AsyncTaskQueue to guarantee sequential delivery.

data: {"message": "Hello"}\n\n
data: {"result": {...}}\n\nEND
STEP 4 • CLIENT REACT STATE

AsyncIterable Render

Client's for await (const chunk of stream) yields typed chunks in real time, re-rendering React UI with incremental data or structured JSON diffs.

setRecipe(chunk);
const final = await output;

Why Next.js App Router + Genkit is Optimal

  • ✓ No CORS overhead: Frontend and AI backend run under the same origin in dev and production.
  • ✓ Zero bundle leakage: Heavy AI dependencies (Node APIs, SDKs, API keys) remain 100% on the server; clients only get schema types.
  • ✓ Durable Reconnection: The StreamManager and x-genkit-stream-id header allow clients to reconnect to an in-flight stream seamlessly.
  • ✓ Dual Integration Paths: Choose between lightweight native @genkit-ai/next/client or rich Vercel AI SDK useChat with GenkitChatTransport.

Wire Protocol & Server-Sent Events (SSE)

// Inbound POST /api/myFlow
Content-Type: application/json
Accept: text/event-stream
x-genkit-stream-id: 8f92-uuid-optional
{"data": {"prompt": "recipe for soup"}}

data: {"result": {"title": "Tomato Basil", "servings": 4, "steps": [...]}}\n\n
END

Agent Architecture, Sessions & Interrupts

How Genkit manages conversational turns, memory, JSON-patch state synchronization, and human approvals.

1

Session Management & Snapshots

Every turn is bound to a Session. State can be server-persisted (SessionStore) or client-managed.

Snapshot Immutability:

Turns generate immutable snapshot IDs. Clients receive JSON Patches (diff) reducing payload transfer overhead across long chats.

2

Human-in-the-Loop Interrupts

Tools can pause execution by returning an interrupt() request (e.g., asking user approval to transfer funds or delete records).

Resuming Turns:

Client responds to the interrupt via chat.resume(). The agent picks up exactly where it paused without re-running earlier tools.

3

Detached Background Workers

Long-running operations run in background mode with periodic heartbeats (30s interval, 60s timeout).

Cancellation:

Clients can abort running agents via the companion /abort endpoint, preventing zombie LLM executions.
