Why Standard PDF Parsers Miss NCTB Diagrams

NCTB textbooks render complex geometry, ray diagrams, and graphs using PDF vector drawing commands (m, l, c, re, W*) rather than embedded PNG/JPEG streams. PyPDF and traditional OCR engines find 0 images on these pages. Azure Document Intelligence Layout visually segments page renders to capture them with precision.

Production Ingestion & Query Snippets

Ready-to-run Python modules using official Azure SDKs for Microsoft Foundry, Document Intelligence, and AI Search.

# 1. Document Intelligence Ingestion with Figures & LaTeX:
from azure.ai.documentintelligence import DocumentIntelligenceClient
from azure.ai.documentintelligence.models import AnalysisFeature, AnalyzeOutputOption, ContentFormat

poller = doc_intel_client.begin_analyze_document(
    model_id="prebuilt-layout",
    analyze_request=open("ingestion/textbooks/physics_bn.pdf", "rb"),
    output_content_format=ContentFormat.MARKDOWN,
    features=[AnalysisFeature.FORMULAS, AnalysisFeature.OCR_HIGH_RESOLUTION],
    output=[AnalyzeOutputOption.FIGURES],
    content_type="application/pdf"
)
result = poller.result()

# 2. Hybrid Multimodal Vector Search with Semantic Ranker:
from azure.search.documents.models import VectorizedQuery

query_vector = openai_client.embeddings.create(
    model="text-embedding-3-large", 
    input=user_query, 
    dimensions=1024
).data[0].embedding

search_results = search_client.search(
    search_text=user_query,
    vector_queries=[VectorizedQuery(vector=query_vector, k_nearest_neighbors=5, fields="text_vector, visual_vector")],
    query_type="semantic",
    semantic_configuration_name="curriculum-semantic-config",
    top=5
)
